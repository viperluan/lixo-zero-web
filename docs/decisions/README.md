# Decisões

Uma decisão de arquitetura vira um arquivo `NNNN-titulo.md`, com o próximo número de quatro dígitos. Cabe uma decisão por arquivo: rota, sessão, contrato com a API ou estado global.

O texto responde só isto:

- Qual era o problema.
- O que foi escolhido e por que fecha o problema.
- Qual efeito isso tem no código.

Correção local e preferência de tela ficam no `CHANGELOG.md` quando a pessoa percebe a mudança, e fora daqui.
